# יומן זיכרון דינאמי

> קובץ append-only. כל סוכן שמקבל פידבק, מגלה כלל חדש, או צריך לתעד שינוי מדיניות — מוסיף כאן רשומה חדשה (ולא עורך רשומות קיימות). סוכנים אחרים קוראים את היומן הזה לפני מענה כדי להתאים את עצמם להעדפות שנצברו לאורך זמן. סוג הרשומה הוא אחד מ: `correction` (תיקון על תוצר קודם), `new_rule` (כלל חדש קבוע), `preference` (העדפת סגנון), `note` (הערה כללית).
